📋 투자 지표 비교 분석

출처: Yahoo Finance · 정상 캐시 최대 6시간 · 갱신 실패 시 최대 7일 이내의 이전 자료를 표시합니다. 조회 상태가 ‘가격만 조회’ 또는 ‘조회 불가’이면 재무 지표는 N/A입니다. 지표별 결산 기간은 다를 수 있습니다. D/E는 차입금 기준입니다.

        

      

    


    
    
    

      

        

          

            
🧮 자유 산식 커스텀 지표

      🕯️ 차트 패턴 · 지지/저항 · 멀티타임프레임 신호
      
          
      캔들 패턴(해머·장악형·샛별형 등)과 피벗 기반 지지·저항선, 돌파·골든크로스 이벤트를 탐지하고, 분봉(60분)·일봉·주봉 지표를 종합해 매수·매도·관망 신호와 신뢰도를 산출합니다.
      
          
      
            
      
            
            삼성전자
            
          
      
        
      
        
      
          
      지지·저항, 이렇게 읽으세요
      
          
      
            
      
              
      지지 (초록) · 하락할 때 살펴볼 가격대
      
              
      가격이 내려올 때 매수세가 유입되어 하락이 멈추거나 반등할 가능성이 있는 구간입니다. 이 화면에서는 분석 기준가보다 아래에 있는 과거 주요 가격대를 지지로 표시합니다.
      
            
      
            
      
              
      저항 (빨강) · 상승할 때 살펴볼 가격대
      
              
      가격이 올라올 때 매도세가 유입되어 상승이 멈추거나 되밀릴 가능성이 있는 구간입니다. 이 화면에서는 분석 기준가 이상에 있는 과거 주요 가격대를 저항으로 표시합니다.
      
            
      
          
      
          
      예시: 기준가가 10,000일 때 지지 9,500(-5%)은 하락 시 가격 반응을 살펴볼 구간이고, 저항 10,500(+5%)은 상승 시 가격 반응을 살펴볼 구간입니다. 선은 해당 가격대의 대표값이며, 정확히 그 가격에서만 반응한다는 뜻은 아닙니다.
      
          
      
            돌파·이탈과 표의 수치 해석
            
        
              
      • 지지 아래로 이탈: 하락을 받치던 가격대가 무너지는 상황입니다. 이후 되올라올 때 그 가격대가 저항으로 작용할 수 있습니다.
        • 
              
      • 저항 위로 돌파: 상승을 막던 가격대를 넘어서는 상황입니다. 이후 되내려올 때 그 가격대가 지지로 작용할 수 있습니다.
        • 
              
      • 기준가 대비: (가격대 ÷ 분석 기준가 − 1) × 100입니다. 음수는 기준가 아래, 양수는 기준가 위이며 예상 수익률이나 반등 확률이 아닙니다. 기준가는 마지막 일봉의 종가 값으로, 장중에는 변동할 수 있습니다.
        • 
              
      • 터치·강도: 이 서비스의 터치는 비슷한 가격대에 모인 과거 고점·저점의 수입니다. 1회는 약, 2회는 중, 3회 이상은 강으로 표시하며, 강도는 성공 확률을 뜻하지 않습니다.
        • 
              
      • 산출 기준: 최근 최대 120개 일봉에서 전후 5개 봉과 비교한 고점·저점을 찾고, 약 1% 이내의 가격대를 묶어 대표값을 계산합니다. 터치 수와 기준가와의 거리로 후보를 고른 뒤 최대 6개를 표시합니다. 가까운 지지·저항은 이 후보 안에서 선택합니다.
        • 
            
      
          
      
          
      지지 도달이 자동 매수 신호이거나 저항 도달이 자동 매도 신호인 것은 아닙니다. 종가가 가격대를 유지하는지, 거래량과 추세가 뒷받침되는지 함께 확인하세요. 돌파 후 다시 되돌아올 수도 있습니다.

      📖 모델별 특성
      
        
      
          
      SVM (Linear/RBF)
      마진 최대화 분류. 고차원 피처에 강함. RBF 커널은 비선형 결정경계.
      
          
      RandomForest
      여러 의사결정트리의 배깅 앙상블. 과적합 방지, 피처 중요도 제공.
      
          
      GradientBoosting
      잔차를 순차 학습하는 부스팅 앙상블. 높은 정확도, 느린 학습.
      
          
      MLP (신경망)
      다층 퍼셉트론. 64→32 은닉층, Adam 옵티마이저, 조기 종료.
      
          
      Ensemble (Voting)
      RF+GB+MLP 다수결. 개별 모델 약점 보완, 안정적 성능.
      
          
      LightGBM
      Leaf-wise 트리 성장. 빠른 학습, 높은 정확도. 대용량 데이터 적합.

      📖 회귀 모델 개요
      
        
      
          
      Linear Regression
      최소제곱법으로 선형 관계 추정. 해석이 쉬우나 과적합 위험.
      
          
      Ridge (L2 정규화)
      가중치 제곱합 페널티로 과적합 방지. α 클수록 계수 축소.
      
          
      Lasso (L1 정규화)
      불필요한 피처 계수를 0으로 수렴(피처 선택 효과).
      
          
      SVR (RBF 커널)
      ε-tube 내 오차를 허용하는 서포트벡터 회귀. 비선형 패턴 포착.

       딥러닝 시계열 예측
      
        
      RNN · CNN · LSTM · Transformer 기반 주가 예측 모델 설계 원리

      실습 환경 (PyTorch/Keras)
      
        
      # PyTorch LSTM 예시 (Google Colab / Jupyter)
import torch, torch.nn as nn

class StockLSTM(nn.Module):
    def __init__(self, input_size=12, hidden=128, layers=2, n_class=3):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden, layers,
                            batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden, n_class)

    def forward(self, x):          # x: (batch, seq, features)
        out, _ = self.lstm(x)
        return self.fc(out[:, -1]) # 마지막 타임스텝

model = StockLSTM()
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss()
        
      
      
      
    
      

    

    
    
      
      
      
        
       거시경제 지표
      
        
      금리·물가·유가·환율 등 매크로 지표가 주식시장에 미치는 영향을 분석합니다.
      
        
      지표 조회 중...
      
        
      
      
      
      
      
        
      📖 거시경제 분석 프레임워크
      
        
      
          
      금리 사이클
      금리 인상 → 성장주 할인율↑ → 가치주 유리. 장단기 금리차(스프레드)로 경기 선행.
      
          
      물가 (CPI/PPI)
      인플레이션 → 원가 상승 → 이익 감소. TIPS 스프레드로 기대 인플레이션 추정.
      
          
      유가 (WTI/Brent)
      에너지 섹터 직접 영향. 유가↑ → 운송/항공 비용↑, 소비재 이익↓.
      
        
      
      
      
    
      

    
    
      
      
      
        
       산업 분석 — 섹터 ETF
      
        
      미국 섹터별 ETF 수익률로 산업별 투자 강도를 비교 분석합니다.
      
        
      섹터 데이터 조회 중...
      
        
      
          
      
            
      
              섹터ETF
              현재가등락등락률
            
      
            
          
      
        
      
      
      
      
      
        
      📖 산업 분석 방법론
      
        
      
          
      포터의 5가지 힘
      공급자/구매자 교섭력, 신규진입 위협, 대체재, 내부 경쟁으로 산업 매력도 평가.
      
          
      산업 수명주기
      도입→성장→성숙→쇠퇴. 성장기 = 높은 PEG, 성숙기 = 안정 배당, 쇠퇴기 = 가치 덫.
      
        
      
      
      
    
      

    
    
      
      
      
        
       재무제표 분석 (DCF·EVA·FCF)
      
        
      
          
          
        
      
        
      
          
      
        
      
      
      
      
      
        
      📖 재무 분석 3대 방법론
      
        
      
          
      
            DCF (할인현금흐름)
      
            
      V = Σ FCFt / (1+r)^t
            + TV / (1+r)^n
      
            미래 FCF를 WACC로 할인해 내재가치 산출. 성장률·할인율에 민감.
          
      
          
      
            EVA (경제적 부가가치)
      
            
      EVA = NOPAT - WACC × 투하자본
      
            자본비용 초과 수익 여부 측정. EVA > 0이면 가치 창출.
          
      
          
      
            FCF (잉여현금흐름)
      
            
      FCF = 영업CF - CapEx
      
            실제 배당·투자 가능 현금. FCF 수익률 = FCF / 시가총액.
          
      
        
      
      
      
    
      

    
    
      
      
      
        
       기술적 분석
      
        
      
          
      
            
      캔들 패턴
      
            
      
              
      ● 망치형 (Hammer) — 하락 추세 반전 신호. 아래 꼬리가 몸통의 2배 이상.
      
              
      ● 유성형 (Shooting Star) — 상승 추세 반전. 위 꼬리가 몸통의 2배.
      
              
      ● 강세 장악형 (Bullish Engulfing) — 이전 음봉을 완전히 포함하는 양봉.
      
              
      ● 도지 (Doji) — 시가≈종가. 추세 불확실성 신호.
      
              
      ● 아침 별 (Morning Star) — 3캔들 패턴. 하락→도지→강한 양봉.
      
            
      
          
      
          
      
            
      엘리어트 파동이론
      
            
      상승 5파 + 조정 3파 = 완전 사이클

 5
3         B
  1    A     C
    2
  4

1·3·5파: 충격파 (추세 방향)
2·4파:   조정파
A·B·C파: 조정 사이클
      
            
      황금비율(0.618·1.618)로 파동 목표가·조정 깊이 계산.
      
          
      
        
      
      
      
      
      
        
      주요 지지/저항 도구
      
        
      
          
      피보나치 되돌림
      고점→저점 이후 38.2%, 50%, 61.8% 수준이 주요 지지·저항.
      
          
      이동평균선 정배열
      MA20 > MA60 > MA120 = 강세 추세. 역배열 = 약세.
      
          
      거래량 분석
      거래량 동반 돌파 = 신뢰도↑. 거래량 없는 돌파 = 페이크아웃 주의.
      
        
      
      
      
    
      

    

    
    
      
      
      
        
       금융상품 이해
      
        
      
          
      
            
      주식 (Equity)
      
            
      
              
      • 보통주: 의결권 + 배당권. 청산 시 후순위.
      
              
      • 우선주: 배당 우선, 의결권 없음. 채권과 주식 중간.
      
              
      • PER = 주가/EPS, PBR = 주가/BPS, PSR = 시총/매출
      
              
      • 배당수익률 = DPS/주가 × 100
      
            
      
          
      
          
      
            
      ETF (상장지수펀드)
      
            
      
              
      • 주식처럼 거래되는 펀드. NAV 추적.
      
              
      • 패시브(지수 추종) vs 액티브 ETF
      
              
      • 레버리지 2x/3x: 일별 수익률 배수 (장기 복리 손실 주의)
      
              
      • 인버스: 지수 하락 시 수익. 헤지 수단.
      
            
      
          
      
          
      
            
      채권 (Bond)
      
            
      
              
      • 금리↑ → 채권 가격↓ (역관계)
      
              
      • 듀레이션: 금리 민감도. D년 채권은 금리 1%↑ → 가격 D%↓
      
              
      • 신용등급: AAA(무위험) → CCC(투기). 스프레드 = 위험 프리미엄.
      
              
      • YTM (만기수익률): 현재 가격 기준 보유 수익률.
      
            
      
          
      
          
      
            
      파생상품
      
            
      
              
      • 선물(Futures): 미래 특정 가격에 매매 약정. 헤지·투기.
      
              
      • 옵션(Options): 콜(매수권) / 풋(매도권). 프리미엄 지급.
      
              
      • 스왑(Swap): 금리·통화 교환. 기관 헤지 도구.
      
              
      • 그릭스: Delta(방향) · Gamma(볼록성) · Theta(시간감소) · Vega(변동성).
      
            
      
          
      
        
      
      
      
    
      

    
    
      
      
      
        
       자산배분 모델
      
        
      
          
      
            
      평균-분산 최적화 (MVO)
      
            
      min w'Σw  s.t. w'μ = r_target
                     Σwi = 1, wi ≥ 0

효율적 프론티어: 동일 기대수익 최소 분산.
샤프 비율 최대화: 접선 포트폴리오.
      
            
      단점: 기대수익 추정 오차에 민감, 극단 배분 발생.
      
          
      
          
      
            
      블랙-리터만 (Black-Litterman)
      
            
      μ_BL = [(τΣ)^-1 + P'Ω^-1P]^-1
       × [(τΣ)^-1 Π + P'Ω^-1 Q]

Π: 시장 균형 수익률 (역최적화)
P: 투자자 뷰 행렬
Q: 뷰 기대수익
Ω: 뷰 불확실성
      
            
      투자자 뷰를 시장 균형에 베이즈 방식으로 결합.
      
          
      
          
      
            
      Risk Parity
      
            
      목표: 각 자산의 위험 기여도 균등화.

RC_i = wi × (Σw)_i / √(w'Σw)

모든 i에 대해 RC_i = 1/n 되도록 w 최적화.
      
            
      레버리지 필요. 저변동성 자산(채권) 비중↑.
      
          
      
        
      
      
      
      
      
        
      간단 자산배분 시뮬레이션
      
        
      로보 어드바이저 > 자산배분·최적화 탭에서 포트폴리오 최적화를 실행해보세요.
      
        
      
          
      60/40 포트폴리오
      주식 60% + 채권 40%. 전통적 균형 포트폴리오. 상관관계가 낮을수록 분산효과↑.
      
          
      올웨더 포트폴리오
      주식 30% · 채권(장기) 40% · 채권(중기) 15% · 원자재 7.5% · 금 7.5%. 레이 달리오 설계.
