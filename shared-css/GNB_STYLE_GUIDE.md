# 공통 GNB 스타일 가이드

적용: PR, IV, FD, ST의 상단 GNB와 연결 메뉴. 신뢰감·프리미엄·안정성·글로벌을 표현하는 절제된 금융 서비스 스타일을 사용한다. 각 사이트의 메뉴와 기능은 유지한다.

| 용도 | 색상 | 규칙 |
| --- | --- | --- |
| 기본 배경 | Navy `#0E2340` | 네 사이트의 상단 영역에 동일 적용 |
| 선택·포커스·브랜드 포인트 | Gold `#C9A86A` | 활성 메뉴 글자와 2px 밑줄, 키보드 포커스, 1px 하단 구분선 |
| 브랜드·강조 글자 | White `#FFFFFF` | Navy 위에 사용 |
| 일반 메뉴 글자 | `#E5EBF3` | Navy 위의 보조 색상 |
| 연결 메뉴 선택 배경 | `#F5F1E9` | Navy 글자와 함께 사용 |

- Pretendard 계열, 브랜드 16px/700, 메뉴 13px/500, 선택 메뉴 650. 모바일은 브랜드 15px, 메뉴 12px.
- 기본 상단 높이 64px. 모바일 메뉴가 많은 사이트는 브랜드·도구 행과 44px 메뉴 행으로 분리한다. 메뉴 행 내부 스크롤로 모든 항목에 접근한다.
- 메뉴는 투명 배경, 절제된 6% White 호버, Gold 활성 표시를 사용한다. 강한 그라데이션과 큰 그림자를 피한다.
- 도구 버튼은 투명 배경과 얇은 테두리, 5px 모서리. 브로커 실행·비상 정지의 상태 색상은 기능 의미를 유지한다.
- 키보드 포커스는 Gold 외곽선으로 표시한다. 모션 감소 설정을 존중한다.
- 본문, 차트, 주문 상태, 좌측 학습 내용은 GNB 스타일로 덮어쓰지 않는다.

소스 정본: `shared-css/common.css`의 Premium finance GNB 블록.
운영 정본: `s3://www.edumgt.co.kr/css/common.css` → CloudFront → `https://www.edumgt.co.kr/css/common.css`.

배포 전후 `python3 shared-css/audit.py`와 `python3 shared-css/audit.py --live`를 실행하고 PC·모바일에서 색상, 활성 메뉴, 포커스, 메뉴 열기, 가로 넘침을 확인한다.
